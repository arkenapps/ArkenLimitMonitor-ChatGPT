STEP 5 - cut the release
-------------------------------------------------------------------

The workflow in .github/workflows/release.yml builds BOTH zips for you

-------------------------------------------------------------------
IF SOMETHING GOES WRONG
-------------------------------------------------------------------

Tag pushed with the wrong version - delete it both places, then re-tag:

git tag -d v1.1.0
git push origin :refs/tags/v1.1.0

Repo name already taken - pick another and reuse it everywhere:

gh repo create arkenapps/ArkenLimitMonitorChatGPT --public --source=. --remote=origin --push

Wrong remote attached - remove and redo step 2:

git remote remove origin

Workflow failed on "Tag must match the manifest version" - the tag and
extension/manifest.json disagree. Check the manifest version:

node -p "require('./extension/manifest.json').version"
