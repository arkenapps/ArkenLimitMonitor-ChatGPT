●Arken Limit Monitor

Privacy Policy

Effective and last updated: August 27, 2026 · Version 1.1

Plain-language summary: the extension runs locally, performs read-only requests to ChatGPT after your consent, never stores your access token, never reads conversations, and does not send usage data to ArkenApps or third parties.

1. Who this policy covers

This policy covers Arken Limit Monitor — Usage Meter for ChatGPT (the “Extension”), published by ArkenApps. The Extension is unofficial and is not affiliated with, endorsed by, or sponsored by OpenAI. “ChatGPT” and “Codex” are used only to describe compatibility.

2. What the Extension does

After you give consent, the Extension shows usage limits, remaining percentages, reset times, optional reset-credit availability, credit balance, spend-control information, and local alerts using data made available to your signed-in browser by ChatGPT. Requests are GET-only and are sent only to https://chatgpt.com.

3. Data accessed

  • A short-lived ChatGPT access token and the current ChatGPT account identifier. These values are read into memory only to authenticate a usage request to ChatGPT.
  • Usage percentages, limit windows, reset timestamps, plan type, and—when available—reset-credit, credit-balance, and spend-control values returned by ChatGPT.
  • Extension settings such as refresh interval, alert threshold, display preferences, notification state, widget position, and consent version.

4. Data the Extension does not access

The Extension does not read or collect your prompts, conversations, responses, passwords, payment-card details, files, address book, browsing history, or cookies. It does not use analytics, advertising trackers, fingerprinting, or remote code.

5. Credential handling

The ChatGPT access token and account identifier are used only during the current in-memory refresh operation. They are not written to browser storage, logged, copied to the clipboard, included in debug output, transmitted to ArkenApps, or shared with any third party. A fresh session value is requested when another usage refresh needs authentication.

6. Local storage and retention

The Extension stores normalized usage results, the last successful refresh time, the selected working usage endpoint, notification-suppression state, consent state, and user settings in the browser’s extension-local storage. This lets the widget restore its state and show the last update while offline. Local data remains until you use Settings → Stop monitoring & delete local data, clear extension data in the browser, or uninstall the Extension.

7. Sharing and transfers

ArkenApps does not receive, sell, rent, disclose, or use the data handled by the Extension. The Extension sends authentication and usage requests only to ChatGPT on your behalf. Donation and support links open only when you choose them and are governed by the destination site’s own privacy policy.

8. Limited use

Access to user data is limited to providing and improving the user-facing usage-monitoring feature described in the store listing. Data is not used for advertising, creditworthiness, lending, surveillance, or unrelated profiling, and is not made available to humans except when required for security, legal compliance, or user-requested support with the user’s permission.

9. Browser permissions

  • chatgpt.com host access: injects the widget and performs read-only ChatGPT session and usage requests after consent.
  • Storage: saves consent, settings, normalized last-known usage, and notification state locally.
  • Notifications: optionally displays a local operating-system alert when usage reaches the user’s threshold.

10. Security and service changes

The Extension uses a fixed allowlist of ChatGPT usage endpoints, GET-only network methods, and no remotely hosted executable code. ChatGPT’s internal endpoints may change without notice, which can temporarily affect functionality. No method of software storage or transmission is guaranteed to be completely secure.

11. Your choices

Monitoring is off until you affirmatively allow it. You can hide the widget, disable notifications, change the refresh interval, or withdraw consent and delete locally stored Extension data at any time from Settings. You may continue using ChatGPT without enabling the Extension.

12. Changes to this policy

If data practices materially change, the Extension will update this policy and request consent again when appropriate. The effective date at the top identifies the current version.

13. Contact

Questions or privacy requests: ArkenApps support page.
